Proxi

/ˈprɒk.si/ — still “proxy”: the y becomes an i.

One click points the system proxy, Terminal, git and npm at your own proxy server — a corporate proxy, an intranet gateway, or a debugging proxy such as Charles. Click again and it all goes back. Proxi only switches settings: it provides no proxy service and relays no traffic.

Free and open sourcemacOS 14 or laterApple silicon and IntelEnglish, 简体中文

One switch, four places

A proxy usually has to be set in System Settings, in Terminal, for git and for npm — and undone in all four when you change networks. A Proxi profile chooses where it applies; the switch sets them all, and turning it off puts everything back.

  • System proxy, through networksetup, for browsers and most apps
  • http_proxy, https_proxy, all_proxy and no_proxy for Terminal windows opened afterwards, plus a one-line command for the ones already open
  • git’s global http.proxy, and ~/.npmrc for npm, pnpm and yarn 1

Points at your own proxy

Each profile is a proxy server you already use: the corporate proxy, an intranet gateway, or a debugging proxy on your Mac. HTTP, SOCKS5 and PAC, an optional sign-in, and a bypass list of its own.

  • Detect finds Charles (8888), Proxyman (9090), mitmproxy (8080) and others running on this Mac
  • Passwords stay in this Mac’s Keychain
  • Test Connection fetches Apple’s test page through the proxy and shows the latency

Scripts, AI assistants and the right network

A proxi command, an MCP server for AI assistants and proxi:// URL commands share one local control interface, with a permission level you choose. Rules switch for you when the network changes.

  • proxi on, proxi use <profile>, proxi off, proxi status, proxi test
  • Turn on the corporate proxy on the office Wi-Fi, off at home
  • AI assistants can check the status, switch profiles and run tests, and nothing more

Every Mac, always current

Profiles and settings sync between your Macs through your own iCloud Drive; passwords don’t leave the Mac they were typed on. New versions install with one click.

  • Merge, keep this Mac’s or use iCloud’s when a second Mac joins
  • Updates are verified (SHA-256 and code signature) before Proxi replaces itself

Small things that add up

⌃⌥P

Turn the proxy on or off from any app. The menu bar icon opens the panel; right-click for a compact menu.

Connection checks

While a proxy is on, Proxi checks now and then that the server still answers and tells you when it doesn’t.

Another app’s proxy

When something else changes the system proxy, Proxi notices and can save it as a profile.

Diagnose

The system proxy, the environment variables, git and npm as they are right now, and Proxi’s log.

Speed in the menu bar

Upload and download speed beside the switch, in the profile’s color while it’s on.

English or Chinese

The interface follows your system language, or pick one in Settings › General.

Install and update

  1. Download Proxi-macos.zip from the latest release and unzip it.
  2. Drag Proxi.app into Applications and double-click it. Releases are signed with a Developer ID and notarized by Apple.
  3. In Settings › Proxy Profiles, add your proxy server (or click Detect), choose where it applies, and flip the switch.

Or let Homebrew do steps 1 and 2:

brew install --cask whrss9527/tap/proxi

Proxi checks GitHub Releases at launch and every 6 hours (you can turn it off). “Update” downloads the build for your chip, compares its SHA-256, replaces Proxi and relaunches; it only installs updates signed by the same developer. Your profiles and settings are kept.

Questions

Is it free?

Yes. Proxi is free and open source under GPL-3.0. It doesn’t provide a proxy service and doesn’t relay any traffic: it only changes settings on your Mac so that they point at a proxy server you already use.

What exactly does it change?

Only what the profile’s scope says: the system proxy for each network service, the http_proxy / https_proxy / all_proxy / no_proxy variables in your login session, git’s global http.proxy and https.proxy, and the proxy lines in ~/.npmrc. Turning the proxy off clears them; for the system proxy you can choose to restore what it was before instead.

Where is my proxy password kept?

In this Mac’s Keychain. It isn’t written to Proxi’s configuration file or synced with iCloud; another Mac asks for it once. While the profile is on, the password is part of the proxy settings Proxi writes, as those tools expect.

Does it need Accessibility?

No. The global shortcut uses the standard hot-key API. Proxi asks for the administrator password to install the command-line tool, and macOS may ask for it when the system proxy changes.

Why does it ask for Location?

Only for switching by Wi-Fi network: since macOS 14, reading the Wi-Fi name requires Location permission. Proxi doesn’t read or store your location, and you can switch by router instead.

Is there a Windows version?

Yes, ProxySwitch for Windows. The two evolve separately.
