Scan Code

Select a QR code or barcode on screen to read it; links can be opened and Wi-Fi codes show the password.

Works with Always available, nothing to selectFree
See how it works Download Pop
QR codes and barcodesWi-Fi passwordsOpen links

How to use it

Select something, hold the right mouse button, swipe. The animation plays the steps one after another; click a step to see it again.

  1. Find the code on screenNothing needs to be selected.
  2. Hold the right mouse buttonAbout a quarter of a second. A short click still opens the usual menu.
  3. Swipe to “Scan Code” and let goIt sits on the ring where you put it, and it’s always in All Actions.
  4. Drag over the codeA Wi-Fi code shows its network and password.
  5. Copy the password

What it does

Drag over a QR code or barcode anywhere on screen, in a photo, a slide or a web page, and Pop reads it.

A Wi-Fi code shows the network name, the password and the security, each ready to copy.

A link can be opened right away; anything else can be copied. If the area holds several codes, Pop reads them all.

Needs Screen Recording permission; without it, the capture may show only the desktop background.

Install it

Plugins aren’t part of the Pop download. Install this one when you need it.

1From Settings

In Pop’s Settings › Actions, find “Scan Code” under Plugins at the top and click Install. It downloads from Pop’s GitHub release in a few seconds and works right away, without a restart.

2Or from the ring

Open All Actions on the ring and search for “Scan Code”. Plugins that aren’t installed are listed after your actions: click it to install, and it runs right away if it can handle what you selected.

3Then use it your way

Put it on the ring in Settings › Ring, give it a shortcut, or run it from Shortcuts and scripts with its link:

pop://run?plugin=scanCode

Uninstall it from the same list when you no longer need it: the plugin and its settings are deleted. After Pop updates, installed plugins are updated with it, and with iCloud sync on, what you install syncs to your other Macs.
