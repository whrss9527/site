Folder Tree

Write the structure of the selected folder as a tree or Markdown list for docs, READMEs or sharing.

Works with Files and foldersFree
See how it works Download Pop
Tree or Markdown├── └──Up to 3 levels

How to use it

Select something, hold the right mouse button, swipe. The animation plays the steps one after another; click a step to see it again.

  1. Select a folder in Finder
  2. Hold the right mouse buttonAbout a quarter of a second. A short click still opens the usual menu.
  3. Swipe to “Folder Tree” and let goIt sits on the ring where you put it, and it’s always in All Actions.
  4. The tree is written outnode_modules is listed by name only.
  5. Copy itPaste it into a README or a message.
  6. Or make it a Markdown list

What it does

Select a folder and Pop writes out what’s inside as a tree (├── └──) or a Markdown list, ready to paste into docs, a README or a message.

Folders are listed first, up to 3 levels deep; hidden files are left out.

Folders such as node_modules, build and Pods are listed by name only, with “…” when they aren’t empty.

The card says how many folders and files it found; copy the one you want.

Install it

Plugins aren’t part of the Pop download. Install this one when you need it.

1From Settings

In Pop’s Settings › Actions, find “Folder Tree” under Plugins at the top and click Install. It downloads from Pop’s GitHub release in a few seconds and works right away, without a restart.

2Or from the ring

Open All Actions on the ring and search for “Folder Tree”. Plugins that aren’t installed are listed after your actions: click it to install, and it runs right away if it can handle what you selected.

3Then use it your way

Put it on the ring in Settings › Ring, give it a shortcut, or run it from Shortcuts and scripts with its link:

pop://run?plugin=folderTree

Uninstall it from the same list when you no longer need it: the plugin and its settings are deleted. After Pop updates, installed plugins are updated with it, and with iCloud sync on, what you install syncs to your other Macs.
