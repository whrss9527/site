Lines

Quote and comma-separate a list (for SQL IN), convert to a JSON array, add or remove numbering, reverse, shuffle; split a comma-separated line into lines.

Works with Selected textFree
See how it works Download Pop
SQL IN ('…')JSON arrayNumber, reverse, shuffle

How to use it

Select something, hold the right mouse button, swipe. The animation plays the steps one after another; click a step to see it again.

  1. Select a column of valuesPasted from a spreadsheet, one per line.
  2. Hold the right mouse buttonAbout a quarter of a second. A short click still opens the usual menu.
  3. Swipe to “Lines” and let goIt sits on the ring where you put it, and it’s always in All Actions.
  4. Every way to write the list
  5. Copy it as a JSON array
  6. Or quote it right there for SQL INReplace puts it in place of the selection.

What it does

Select a column of values, one per line, and quote them for an SQL IN list: single quotes and commas, with quotes inside escaped.

Or double-quote them, make a JSON array, join them with commas, add or remove numbering, remove quotes, reverse or shuffle them.

A single line separated by commas, semicolons, tabs or vertical bars (Chinese punctuation too) is split into lines.

Copy any version, or put it in place of the selection.

Install it

Plugins aren’t part of the Pop download. Install this one when you need it.

1From Settings

In Pop’s Settings › Actions, find “Lines” under Plugins at the top and click Install. It downloads from Pop’s GitHub release in a few seconds and works right away, without a restart.

2Or from the ring

Open All Actions on the ring and search for “Lines”. Plugins that aren’t installed are listed after your actions: click it to install, and it runs right away if it can handle what you selected.

3Then use it your way

Put it on the ring in Settings › Ring, give it a shortcut, or run it from Shortcuts and scripts with its link:

pop://run?plugin=lineTools

Uninstall it from the same list when you no longer need it: the plugin and its settings are deleted. After Pop updates, installed plugins are updated with it, and with iCloud sync on, what you install syncs to your other Macs.
