How plugins work

A plugin is a tool that isn’t part of the Pop download. Once installed, it works like any other action: on the ring, in All Actions, with a shortcut or a pop:// link.

Install in seconds

Under Plugins at the top of Settings › Actions, click Install. It downloads from Pop’s GitHub release and works right away, without a restart.

Or right from the ring

Search All Actions on the ring: plugins you haven’t installed are listed after your actions. Click one and it installs, then runs on what you selected.

Kept up to date

When Pop updates, installed plugins are replaced with the matching new versions. With iCloud sync on, what you install syncs to your other Macs.

Gone when you’re done

Each plugin shows its download size and the space it takes. Uninstall deletes the plugin and its settings and takes it off the ring.

Text

Read, tidy, extract and present the text you select.

Translate Screenshot

Select an area of the screen, recognize its text and translate it (offline)

Speak

Read the selected text aloud with a system voice; use it again while speaking to stop. It can also save the speech as an audio file

Save Web Page

Save the whole page at the selected URL to Downloads as one long PDF (with selectable, searchable text) or a long image, or save just the article text as Markdown

Text to Image

Lay out the selected text as a long image that reads well on a phone (1080 pixels wide) on a white, cream or dark background; copy it, save it or pin it to the screen

Large Type

Show the selected text across the whole screen, handy for showing someone a phone number, Wi-Fi password or pickup code; click or press any key to close

Font Preview

Show the selected text (or a sample) in every font on your Mac, filter by Chinese, Western, monospaced or favorite fonts and only those that can show all of it; copy the font name or CSS, or copy it as an image; select font files to preview and install them

Clean Up Text

Join lines, remove blank lines and extra spaces, space Chinese and Latin text, full-width to half-width, Simplified ↔ Traditional Chinese, Pinyin, sort and deduplicate lines

Extract Info

Find links, email addresses, phone numbers and IP addresses in text and copy them one by one or together

ID Numbers

Chinese ID numbers, unified social credit codes and bank card numbers: check the check digit and read out birth date, age, sex, region and registration authority, offline

Lines

Quote and comma-separate a list (for SQL IN), convert to a JSON array, add or remove numbering, reverse, shuffle; split a comma-separated line into lines

Add to Reminders

Find a time in the selected Chinese text (明天下午 3 点, 周五, 10 月 8 日, 半小时后…) and add it to Reminders or Calendar

Spell Check

Find misspelled words and suggest corrections you can apply directly (built-in macOS spell checking, offline)

Compare Text

Compare the selected text with the text on the clipboard and mark deletions and additions

Emoji & Symbols

Search emoji in Chinese, pinyin or English (“笑”, “猫”, “smile”), plus everyday special symbols: check marks, arrows, circled numbers, math, units and currency, Greek letters, superscripts and subscripts. Click one to insert it where you are typing, or select a word first to replace it with an emoji

Inbox

Append the selected text to “Documents/Pop 收集箱.md”

Convert

Turn data from one shape into another: tables, Markdown, dates, numbers, colors.

Number Statistics

Get the sum, average, median, max and min of a list of numbers

Chart

Turn a selected table, lines of “name value” or a list of numbers into a column, bar, line or pie chart, then copy it as an image or save it to Downloads

Case

Convert between uppercase, lowercase, camelCase, snake_case and more

Encode & Decode

Encode and decode Base64, URL, Unicode and HTML entities

YAML ↔ JSON

Convert selected JSON to YAML or YAML to JSON, keeping key order

Format XML

Format or minify the selected XML (SVG, plist and XHTML too)

Format SQL

Put each clause of the selected SQL on its own line, uppercase keywords and indent subqueries, or squeeze it onto one line

Convert Table

Convert between text copied from spreadsheets, CSV and Markdown tables, or to JSON

Markdown Rich Text

Preview the selected Markdown formatted, or copy it as formatted text that keeps its formatting when pasted into documents, mail or notes

Convert to Markdown

Convert formatted text selected in web pages and documents to Markdown: headings, lists, links, bold, code, tables

Markdown Table of Contents

Create a table of contents from the headings in the selected Markdown, with links to each heading (GitHub-style anchors)

Date Difference

Select two dates (e.g. “2026-09-29 to 2026-12-25”) to get the days, weeks and months between them and how many are workdays

Time Zones

Select a time such as “3pm PST” or “9 pm Beijing time” to see it in the cities you use. Drag the slider to try other times and find when everyone is at work

Calendar

A month calendar with lunar dates, solar terms and festivals; select a date, festival or lunar date to jump to that day

Numbers

Bases, thousands separators, RMB in words

Contrast

Select two colors (e.g. “#333333 #FFFFFF”) to get the text/background contrast ratio and whether it meets WCAG AA and AAA

Developer

Small tools for code: hashes, QR codes, JWTs, regular expressions, cron.

Hash

Compute MD5, SHA-1, SHA-256 and SHA-512 of text or files

QR Code

Generate a QR code from text or a link (letters and digits can also become a barcode); with an image selected, read the QR codes and barcodes in it

Base64 Image

Show Base64 or data: image data as an image to copy, save or pin

Random

Generate UUIDs, passwords and random numbers to paste into the current field

Parse Link

Split a link into scheme, host, path and decoded parameters, and remove tracking parameters such as utm_source

Decode JWT

Decode the selected JWT and list claims such as issuer and expiry (decoding only; the signature isn’t verified)

Regex Tester

Try regular expressions on the selected text: live highlighting of matches, groups and replacements

Cron Expression

Explain a cron expression (e.g. */15 9-17 * * 1-5) in words and list the next run times

Code Screenshot

Render the selected code as an image (dark editor, syntax highlighting, gradient background) to copy, save or pin

JSON to Code

Generate TypeScript, Swift, Go and Kotlin type definitions from the selected JSON

Character Info

See each character’s Unicode code point, name and encoding; find and remove invisible characters such as zero-width spaces

Screen & Images

Capture the screen and work on images without opening an editor.

Recognize Table

Recognize a table in a screenshot or image as a Markdown table, CSV or tab-separated text (macOS 26; earlier versions recognize plain text)

Scan Code

Select a QR code or barcode on screen to read it; links can be opened and Wi-Fi codes show the password

Beautify Screenshot

Put a screenshot on a gradient background with padding, rounded corners and a shadow, optionally filled out to 1:1, 4:3 or 16:9, so it looks good in posts and slides. Uses the selected image, or lets you select an area of the screen first

Remove Background

Remove the background of the selected image, keeping only people, animals or objects (offline)

Convert Images

Convert the selected images to PNG, JPEG or HEIC, halve their size, compress them (or under a given size), rotate, flip, or remove location and capture info; results are saved next to the originals

Stitch Images

Stitch the selected images vertically or horizontally in file name order, or make an animated image, saved next to the first one

Split Image

Cut the selected image into a 3 × 3 or 2 × 2 grid (cropped to a square around the subject) or three squares side by side, or cut a long image into pages. The pieces are numbered in posting order and saved in a folder next to the original

Compare Images

Compare two selected images side by side, with a swipe divider or a translucent overlay, or mark the pixels that differ in red and box each area that changed. Handy for before-and-after screenshots and for checking a build against its design

Make App Icon

Make app icons from the selected image: a macOS .icns and an Xcode icon set (a rounded square the size of the system’s app icons), a 1024 iOS icon and a website favicon, saved in a folder next to the image

Watermark

Tile semi-transparent text diagonally across the selected images or PDFs and save copies next to the originals

ID Photo

Give a portrait a white, blue or red background and crop it around the face to 1-inch or 2-inch ID sizes (300 dpi); processed on this Mac and saved as a copy next to the original

Crop Image

Crop the selected images to 1:1, 4:3, 3:4, 16:9 or 9:16, centered on the subject; a copy is saved next to the original

Redact

Find faces, phone numbers, email addresses, ID and bank card numbers and license plates in the selected images, pixelate them and save a copy; recognized on this Mac, and the copy carries no capture info or location

Image Colors

Find the main colors in an image, listed by area; click to copy a value

Screen Ruler

Freeze the screen and measure distances from the pointer to the edges around it; drag to measure an area; click to copy the size

Picture in Picture

Float a live view of any window in a corner of the screen, above all other windows, to keep an eye on a video, a call or a download while you work; drag to move it, scroll to resize it and double-click to go back to the window

Recording & Presenting

Record the screen or your voice, and point things out while you present.

Record Screen

Drag out an area, click a window or press Return to record the whole screen as MP4; can include the Mac’s sound or the microphone and show clicks and keystrokes, and the recording can then be turned into a GIF. Use it again while recording to stop

Voice Recorder

Record sound from the microphone and save it as an .m4a file in Downloads; while recording, a small bar at the top of the screen shows the time and level and can pause, and you can transcribe the recording afterwards. Use it again while recording to stop

Scrolling Screenshot

Select an area, then scroll down while Pop captures it into one long image: whole web pages, chat histories and long documents, with text recognition afterwards if you like. Use it again while capturing to finish

Show Keystrokes

Show the shortcuts you press (⌘C, ⇧⌘4, arrow keys and so on) at the bottom of the screen for demos and tutorials; ordinary typing isn’t shown. Use it again to turn it off. Screen recordings can include them too

Draw on Screen

Draw right on the screen for demos and tutorials: pen, highlighter, arrow, rectangle and ellipse. Strokes can fade after a few seconds or stay while you use the windows underneath, and screen recordings include them. Press Esc or use it again to finish

Camera Bubble

Show the camera in a small round window in a corner of the screen, so you appear in tutorials and demos. Drag to move it, scroll or double-click to resize, right-click to change the shape or camera. Use it again to close

Highlight Pointer

Put a yellow halo around the pointer that ripples when you click, so people can always find it in demos and tutorials. Use it again to turn it off

Spotlight

Dim the screen except for a circle around the pointer that follows it, so people look where you point in demos and tutorials. Screen recordings include it; use it again to turn it off

Screen Zoom

Magnify the area around the pointer in demos and tutorials so small text is easy to read. It zooms into a snapshot of the screen: move the pointer to look around, scroll or press ↑↓ to change the magnification, and click or press Esc to go back

Teleprompter

Put the selected script in a teleprompter at the top of the screen that scrolls up at the speed you set, so you can read it to the camera. Space pauses, ↑ and ↓ change the speed, and screen recordings leave it out

Files & System

Work on the files you select in Finder, and on the Mac itself.

Folder Tree

Write the structure of the selected folder as a tree or Markdown list for docs, READMEs or sharing

Lines of Code

Count code files and lines per language in the selected folders; copy as a Markdown table

Compare Files

Compare the two selected text files (code, Markdown, config, CSV…), marking removed and added lines and the changed words in them; the older file by modification date is the original

Batch Rename

Rename the selected files together: numbering, find and replace, prefix and suffix, photo capture date, case. Preview first and undo afterwards.

Zip and Unzip

Compress the selected files or folders into a zip in the same folder, or extract the selected zip files into folders next to them

Open in Terminal

Open the selected folder in Terminal (for files, the folder they’re in)

PDF

Combine the selected images and PDFs into one PDF in file name order. With a single PDF, save each page as an image, copy its text, extract or split pages, add page numbers, add or remove a password, or compress it. For a scan, recognize the text and save a copy you can search and copy from

Convert Video

Convert the selected videos to GIF or MP4, compress to 720p, extract audio, or make a contact sheet of 16 evenly spaced frames; results are saved next to the originals

Trim

Cut a range from the selected audio or video (by start and end time), saved next to the original

Transcribe

Turn speech in recordings and videos into text and SRT subtitles saved next to the original; Mandarin, English, Cantonese and Japanese, recognized on this Mac when it supports it

AirDrop

Send the selected files, images, links or text to a nearby iPhone, iPad or Mac with AirDrop

Send to Phone

Scan a QR code with your phone to download the selected files or images (folders are zipped first) or get the selected text, and upload files from the phone to Downloads. The phone and Mac just need to be on the same Wi-Fi; Android works too.

Window Layout

Move the current window to the left or right half, a third, maximize, center it, or move it to another display

Keyboard Shortcuts

List every keyboard shortcut in the current app’s menus; search them and click one to run it

Keep Awake

Keep the display on and the Mac awake for a while: for reading, presenting or waiting for downloads

System Actions

Lock the screen, turn off the display, sleep, start the screen saver, switch between Dark and Light Mode, mute, hide or show desktop icons, show hidden files, or eject all disks

Quit Apps

List running apps and how much memory and CPU each one uses. Quit an app with a click, force quit one that doesn’t respond, or quit all the others at once before a meeting or a demo

Uninstall App

Uninstall the selected app: find the settings, caches and containers it left in your Library, see how much space each takes, and move them to the Trash together. Check only the leftover files to reset the app to a fresh install

App Info

See which chips the selected app is built for, who signed it, whether it is notarized and sandboxed, which permissions it may ask for, what it is built with and where it was downloaded from, ready to copy

Battery Info

See the charge, maximum capacity (health), cycle count, condition and temperature of a MacBook battery, how many watts are going in or out, the charger’s wattage, and how long until it’s full or empty; also lists the battery levels of connected Bluetooth keyboards, mice, trackpads and headphones

System Info

See this Mac’s model, chip and cores, memory, macOS version, uptime, free space on the startup disk, and each display’s resolution and refresh rate, and copy it all at once for bug reports or when asking for help

Sound Devices

Switch where sound plays and which microphone is used in one go: speakers, headphones, AirPods, displays or AirPlay, and adjust the volume or mute

Bluetooth Devices

Connect or disconnect paired Bluetooth devices in one go: AirPods and other headphones, keyboards, mice, trackpads and game controllers, with the battery level of connected keyboards and mice

Resolution

Change each display’s resolution (what it looks like) and refresh rate, or pick the main display; after a change on an external display, click Keep within 15 seconds or it switches back

Disk Speed

Measure how fast a hard drive, USB stick or portable SSD writes and reads sequentially. Select a file or folder on a disk to test that disk, or nothing to test the startup disk

Clean Keyboard

Lock the keyboard for a minute so you can wipe it without typing anything; brightness and volume keys are blocked too. Click End Cleaning with the mouse to stop any time

Timer

Countdown: choose a duration, or select text such as “25 min” or “1:30” to start right away. Plays a sound and sends a notification when time’s up. There’s also a Pomodoro timer: 25 minutes of focus, then a 5-minute break, over and over

Break Reminder

Reminds you to take a break after a stretch at the computer; stepping away counts as a break, and it stays quiet during videos and meetings

White Noise

Play white, pink or brown noise, rain or waves to cover the chatter around you while you focus or nap, with a volume control and a sleep timer. The sound is generated on your Mac and keeps playing after you close the card; pause or stop it from the headphones icon in the menu bar

Folder Tools

See what takes up the most space in a folder, find files with identical contents and compare two folders, then move what you don’t need to the Trash

Tidy Folder

Sort the files at the top of the selected folder (or Downloads if nothing is selected) into subfolders by type or by month, or sort photos and videos by the date they were taken. Preview first and undo afterwards

New File

Create a text, Markdown, web page or script file in the selected folder (or the folder open in Finder), or save the selected text or the text or image on the clipboard as a file

File Encoding

See which encoding (UTF-8, GBK, Big5…) and line endings the selected text files use, and convert them to UTF-8 (with a BOM so Excel opens CSV files correctly) or GBK, with LF or CRLF line endings. Undo afterwards

Similar Photos

Find burst shots and photos saved twice or resized in the selected folder (or images), keep the sharpest one of each group and move the rest to the Trash

Media Info

See the codec, resolution, frame rate and bit rate of the selected video or audio, whether it’s HDR, its audio and subtitle tracks, and which device shot it where; save a copy without the location if it has one

Subtitles

Shift the selected subtitles (SRT, WebVTT, ASS, LRC) earlier or later, convert between frame rates, remove style tags and hearing-impaired descriptions, and save them as SRT, WebVTT, LRC or plain text; select two to merge them into one bilingual file

Encrypt Files

Put the selected files and folders into a password-protected (AES-256) disk image that opens on any Mac with a double-click and the password; use it before sending files or saving them to a USB drive or cloud storage

Mouse Wheel

Reverse the scroll direction of a mouse wheel while the trackpad keeps natural scrolling, or make it scroll faster; only wheel mice change, trackpads and Magic Mouse stay as they are

Hold to Quit

Quit apps only after holding ⌘Q for a moment (or pressing it twice), so a stray ⌘Q never closes a whole app; some apps can still quit right away

Sleep Timer

Put your Mac to sleep, turn off the display, lock the screen or shut down after a while or at a set time. A last-minute note lets you postpone or cancel, and the volume fades out before sleep or shutdown
