Pop 插件 · 文件和系统

字幕工具

选中字幕文件（SRT、WebVTT、ASS、LRC），整体提前或推后、换帧率、去掉样式标签和听障说明，转成 SRT、WebVTT、LRC 或纯文字；选两份字幕可以合成一份双语字幕。

处理 文件和文件夹免费
看看怎么用 下载 Pop
SRT · WebVTT · ASS · LRC调时间、清理合成双语字幕

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中字幕文件选两份就能合成双语字幕。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「字幕工具」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 整体推后 1.5 秒预览跟着变。
  5. 去掉样式标签和听障说明
  6. 存好可以撤销。

能做什么

选中字幕文件（SRT、WebVTT、ASS/SSA、LRC），整体提前或推后，或者换帧率（23.976、24、25 互相换）。

去掉样式标签（斜体、颜色、位置、ASS 的特效）和听障说明（[音乐]、(笑声)）。

转成 SRT、WebVTT、LRC 或者纯文字，卡片上能看到处理以后的前几句。格式不变时直接改原文件（存成 UTF-8），可以撤销；换了格式另存一份。

选两份字幕（比如中文和英文）可以合成一份双语字幕，上面一行用哪一份可以选。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「字幕工具」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「字幕工具」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=subtitles

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多文件和系统

目录结构

把选中文件夹里的目录结构写成树形或者 Markdown 列表，贴进文档、README 或者发给别人

代码行数

按语言统计选中的文件夹里有多少个代码文件、多少行，可以复制成 Markdown 表格

对比文件

对比选中的两个文本文件（代码、Markdown、配置、CSV……），标出删去和新增的行，改动的地方逐词标出；按修改时间，旧的当原文

批量重命名

给选中的文件统一改名：编号、替换文字、加前后缀、按照片的拍摄时间、改大小写，先看预览再改，改完可以撤销

压缩和解压

把选中的文件或文件夹压缩成 zip，存在原来的文件夹里；把选中的 zip 解压到旁边的同名文件夹里

在终端打开

在「终端」里打开选中的文件夹（选中文件时打开它所在的文件夹）
