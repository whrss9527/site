加到提醒事项

从选中的文字里认出时间（明天下午 3 点、周五、10 月 8 日、半小时后……），加到「提醒事项」或者「日历」。

处理 选中的文字免费
看看怎么用 下载 Pop
「周五下午 3 点」提醒事项日历

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中文字
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「加到提醒事项」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 认出时间和要做的事
  5. 想改就改标题、日期、时间都能改。
  6. 加到「提醒事项」或者加到「日历」：没说几点的是全天日程。

能做什么

选中一句话，比如「明天下午 3 点和设计组过一遍截图」「周五之前交周报」「半小时后给妈妈打电话」，Pop 认出时间和要做的事：今天明天后天、周几和下周几、几月几号、几天后、半小时后、上午下午晚上几点几分、几点半、一刻都认得。

英文交给系统识别（tomorrow at 3pm）。

标题、日期和时间都可以再改，然后加到「提醒事项」（说了几点的到点提醒）或者「日历」（没说几点的是全天日程），原文放在备注里。

第一次用时系统会问要不要允许；日历只申请写入权限，不读你的日程。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「加到提醒事项」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「加到提醒事项」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=reminder

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多文字

截图翻译

框选屏幕上的一块区域，识别里面的文字并翻译（离线）

朗读

用系统语音朗读选中的文字，朗读中再用一次就停止；也能读出来存成音频文件

网页存档

把选中的网址整页存成一页长 PDF（文字能选、能搜）、一张长图，或者只把正文存成 Markdown，放在「下载」里

文字转图片

把选中的文字排成一张手机上看着舒服的长图（宽 1080 像素），白底、米黄、深色三种底色，可以复制、存储或贴到屏幕上

大字显示

把选中的文字铺满整个屏幕，给别人看电话号码、Wi-Fi 密码、取件码都方便；点一下或按任意键关闭

字体预览

用这台 Mac 上的每一种字体显示选中的文字（没选中时用示例），按中文、西文、等宽、收藏筛选，只看能完整显示的；复制字体名、CSS，或者复制成图片；选中字体文件时先预览再安装
