万年历

月历上每天写着农历、节气和节日；选中一个日期、节日或者农历日子，翻到那一天。

处理 随时可用，不用选中内容免费
看看怎么用 下载 Pop
农历和节气翻到节日1900–2100

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中一个日期或者节日什么都不选，就看这个月。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「万年历」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 直接翻到那一天今天以后最近的那个重阳节。
  5. 点一天看看绿色的是节气，红色的是节日。
  6. PageDown 换到下个月
  7. 按 T 回到今天
  8. ⌘C 复制这一天连同农历和节日。

能做什么

一个月的月历，每天写着农历、节气和节日（春节、中秋这些农历节日，元旦、国庆、母亲节这些公历节日），今天的日期标出来。

选中「2026-10-01」「10月1日」「中秋节」「冬至」「农历八月十五」这样的文字再用，直接翻到那一天；节日、农历日子翻到今天以后最近的那次。

下面写着选中的那天是星期几、离今天几天、第几周，还有下一个节气在哪天。

方向键换一天，PageUp、PageDown 换月，T 回到今天，⌘C 复制这一天；农历和节气可以关掉，只看公历。

节气按北京时间算到哪一天，1900 到 2100 年每一个都和天文算法对过。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「万年历」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「万年历」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=calendar

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
