数字转换

进制转换、千分位、人民币大写。

处理 数字免费
看看怎么用 下载 Pop
0x35E8 · 0b1101…13,800人民币大写

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中一个数
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「数字转换」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 各种进制一次列出
  5. 英文、中文读法
  6. 复制人民币大写开发票、写合同时用。

能做什么

选中一个数，换算成十进制、十六进制、八进制、二进制。

还有千分位、英文读法、中文读法，以及人民币大写（壹万叁仟捌佰元整）。

认得 0x、0b、0o 开头的写法，千分位、小数、负数也行。

每一行都能复制，也能直接替换原文。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「数字转换」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「数字转换」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=numberConvert

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
