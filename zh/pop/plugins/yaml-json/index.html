YAML 和 JSON

选中 JSON 转成 YAML，选中 YAML 转成 JSON，键的顺序不变。

处理 选中的文字免费
看看怎么用 下载 Pop
JSON → YAMLYAML → JSON键的顺序不变

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中 JSON 或者 YAML
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「YAML 和 JSON」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. JSON 转成 YAML键的顺序不变。
  5. 按 ⌘C 复制选中的是 YAML 就转成 JSON。

能做什么

选中 JSON 转成 YAML，选中 YAML（配置文件、CI 工作流……）转成 JSON。

键的顺序不变，数字按原样保留。

认得注释、多行文字（| 和 >）、「- key: value」、[a, b] 和 {a: 1} 这些常用写法，写错了会指出是第几行。

结果可以复制、替换原文；YAML 转成的 JSON 还能复制压缩版。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「YAML 和 JSON」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「YAML 和 JSON」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=yamlJSON

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
