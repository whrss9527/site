切分图片

把选中的图片切成九宫格、四宫格（对准画面里的主体裁成正方形）或者横着三张，长图切成几页；按发出去的顺序编号，存在原图旁边的文件夹里。

九宫格横切三张长图分页

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 在访达里选中一张照片
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「切分图片」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 对准主体切九宫格用不到的部分压暗，编号就是发出去的顺序。
  5. 也可以切四宫格、横切三张
  6. 切好存下切好的放进一个新文件夹。

能做什么

把照片切成九宫格、四宫格（先对准画面里的主体裁成正方形），或者横着切成三张正方形。

长图（比如滚动截图）可以切成几页，每页一样长，最多 9 页。

预览里压暗用不到的部分，画出格线和编号，编号就是发出去的顺序：从左到右、从上到下。

切好的存在原图旁边的新文件夹里，照片存成 JPEG，截图存成 PNG；上次用的切法会记住。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「切分图片」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「切分图片」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=splitImage

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多屏幕与图片

识别表格

识别截图或图片里的表格，转成 Markdown 表格、CSV 或者制表符分隔（macOS 26；更早的系统按普通文字识别）

扫码

框选屏幕上的二维码或条形码，识别里面的内容；链接可以直接打开，Wi-Fi 二维码列出密码

截图美化

给截图加上渐变背景、留白、圆角和阴影，可以补成 1:1、4:3、16:9，发文章、做演示更好看；选中图片就用它，没选中就先框选屏幕上的一块

抠图

去掉选中图片的背景，只留下人、动物或物品（离线）

图片转换

把选中的图片文件转成 PNG、JPEG、HEIC，缩小一半、压缩体积或者压到指定大小以内，旋转、左右翻转，或者去掉照片里的位置和拍摄信息；结果存在原图旁边

拼接图片

把选中的几张图片按文件名的顺序竖着或者横着拼成一张，或者合成一张动图，存在第一张旁边
