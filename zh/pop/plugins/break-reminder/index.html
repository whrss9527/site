休息提醒

连续用电脑一段时间提醒你起来活动、看看远处；离开一会儿就算休息过了，看视频、开会时不打扰。

处理 随时可用，不用选中内容免费
看看怎么用 下载 Pop
每 45 分钟离开就算休息开会时不打扰

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 什么都不用选在哪儿都能用。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「休息提醒」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 打开它每 45 分钟休息 5 分钟，都可以改。
  5. 45 分钟后，屏幕上方提醒你离开一会儿就算休息过了。
  6. 休息一下上方的小条倒计时，Esc 提前结束。
  7. 休息完了响一声

能做什么

打开以后，连续用电脑 45 分钟（20 分钟到 1 个半小时可选）就在屏幕上方提醒你休息一下，可以马上休息、5 分钟后再提醒或者跳过。

休息 20 秒到 10 分钟，倒计时显示在上方的小条里，也可以选「休息时盖住屏幕」，按 Esc 随时提前结束；休息完了响一声。

离开电脑够久（一次休息的时长，至少 3 分钟）就算休息过了，合上盖子睡着的时间也算在里面，回来重新计时。

有 App 在放视频、开视频会议时不提醒，那段时间也不算休息。Pop 下次启动时接着计时。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「休息提醒」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「休息提醒」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=breakReminder

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多文件和系统

目录结构

把选中文件夹里的目录结构写成树形或者 Markdown 列表，贴进文档、README 或者发给别人

代码行数

按语言统计选中的文件夹里有多少个代码文件、多少行，可以复制成 Markdown 表格

对比文件

对比选中的两个文本文件（代码、Markdown、配置、CSV……），标出删去和新增的行，改动的地方逐词标出；按修改时间，旧的当原文

批量重命名

给选中的文件统一改名：编号、替换文字、加前后缀、按照片的拍摄时间、改大小写，先看预览再改，改完可以撤销

压缩和解压

把选中的文件或文件夹压缩成 zip，存在原来的文件夹里；把选中的 zip 解压到旁边的同名文件夹里

在终端打开

在「终端」里打开选中的文件夹（选中文件时打开它所在的文件夹）
