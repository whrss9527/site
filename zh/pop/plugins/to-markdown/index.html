转成 Markdown

把网页、文档里选中的带格式文字转成 Markdown：标题、列表、链接、粗体、代码、表格。

处理 选中的文字免费
看看怎么用 下载 Pop
标题 · 链接 · 表格任务列表 · 代码块网页、邮件、文档

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中带格式的文字网页、邮件、文档里都行。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「转成 Markdown」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 转成 Markdown标题、粗体、列表都在。
  5. 复制下来也可以贴到屏幕上，边看边写。

能做什么

在网页、邮件、文档里选中一段带格式的文字，转成 Markdown。

标题、段落、粗体、斜体、删除线、链接、图片、列表（包括任务列表）、引用、代码块（带语言）、表格都保留。

只有 RTF 的 App（比如文本编辑、Pages）按字体转换粗体、斜体、等宽字体、链接和列表。

可以复制，也可以贴到屏幕上。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「转成 Markdown」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「转成 Markdown」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=toMarkdown

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
