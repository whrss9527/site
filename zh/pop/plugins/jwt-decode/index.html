JWT 解码

解码选中的 JWT，列出签发者、过期时间等声明（只解码，不验证签名）。

处理 选中的文字免费
看看怎么用 下载 Pop
过期时间一眼看到换成本地时间只解码

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中一个 JWT
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「JWT 解码」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 声明都解出来了
  5. 看看什么时候过期换成本地时间，还标着还有多久。
  6. 复制解码后的内容

能做什么

选中一个 JWT，列出算法、签发者、主题、受众，签发时间、生效时间、过期时间都换成本地时间。

过期时间后面标着是否已经过期，没过期的写着还有多久。

完整显示解码后的内容，排好了版，可以复制，也可以复制头部。

只解码，不验证签名。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「JWT 解码」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「JWT 解码」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=jwtDecode

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
