哈希

计算文字或文件的 MD5、SHA-1、SHA-256、SHA-512。

处理 选中的文字、文件和文件夹免费
看看怎么用 下载 Pop
MD5 · SHA-1SHA-256 · SHA-512文字或文件

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 在访达里选中一个文件选中一段文字也行。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「哈希」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 四种哈希一次算好大文件分块读，不会一次读进内存。
  5. 复制要用的那一个和下载页上写的校验值对一对。

能做什么

选中文字或文件，一次算出 MD5、SHA-1、SHA-256、SHA-512，哪一个都能单独复制。

文字按 UTF-8 计算；文件分块读取，很大的安装包、磁盘映像也没问题。

选中好几个文件时，列出每个文件的 SHA-256，一次最多 20 个。

文件夹没法计算哈希，要选里面的文件。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「哈希」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「哈希」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=hash

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多开发

二维码

把文字或链接生成二维码（英文字母和数字还能生成条形码）；选中图片时识别里面的二维码和条形码

Base64 图片

把 Base64 或 data: 开头的图片数据显示成图片，可以复制、保存、贴到屏幕

随机生成

生成 UUID、密码和随机数字，可以直接粘贴到当前输入框

链接解析

拆开链接的协议、主机、路径和每个参数（解码后），去掉 utm_source 这类跟踪参数

JWT 解码

解码选中的 JWT，列出签发者、过期时间等声明（只解码，不验证签名）

正则测试

在选中的文字里试正则表达式：实时标出每处匹配、列出分组，也可以试替换
