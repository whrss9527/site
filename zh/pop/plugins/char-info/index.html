字符信息

查看每个字符的 Unicode 码点、名称和编码；找出并去掉零宽空格这类看不见的字符。

处理 选中的文字免费
看看怎么用 下载 Pop
U+200BUTF-8 · UTF-16看不见的字符

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 选中几个字符
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「字符信息」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 码点、名称、编码带肤色的表情拆开列出。
  5. 藏着看不见的字符两个零宽空格。
  6. 去掉后替换原文也可以去掉后复制。

能做什么

选中几个字符，看每个字符的 Unicode 码点、名称和 UTF-8 编码，表情这类 U+FFFF 以外的字符还有 UTF-16；带肤色的表情会拆开列出。

能找出零宽空格、不换行空格、BOM、双向控制符这类看不见的字符，从网页、聊天软件复制的文字里常有。

可以去掉后替换原文，也可以去掉后复制；不换行空格换成普通空格。

20 个字以内逐个列出，更长的文字只检查看不见的字符。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「字符信息」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「字符信息」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=charInfo

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。
