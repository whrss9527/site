白噪音

放白噪音、粉红噪音、棕色噪音、雨声或者海浪，盖住周围的说话声，专心做事、午睡时用；可以调音量、定时停止。声音在本机实时生成，关掉卡片也接着放，菜单栏的耳机图标可以暂停、停止。

处理 随时可用，不用选中内容免费

雨声 · 海浪 · 噪音定时停止本机实时生成

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 什么都不用选在哪儿都能用。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「白噪音」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 选一种声音
  5. 点「雨声」就放
  6. 定时停止快到点时慢慢变小声。
  7. 关掉卡片，接着放菜单栏的耳机图标可以暂停、停止。

能做什么

放白噪音、粉红噪音、棕色噪音、雨声或者海浪，盖住周围的说话声和键盘声，专心做事、午睡时用。

声音在本机实时生成，不用下载音频；点一种就放，再点一下暂停，换声音、调音量、暂停和停止都是慢慢变过去的，不会「啪」的一声。

可以定时 15 分钟、30 分钟、1 小时或者 2 小时后停下，最后几秒慢慢变小声。

关掉卡片也接着放，菜单栏的耳机图标可以暂停、接着放、停止；放哪种、多大声、定时多久都会记住。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「白噪音」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「白噪音」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=focusSounds

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多文件和系统

目录结构

把选中文件夹里的目录结构写成树形或者 Markdown 列表，贴进文档、README 或者发给别人

代码行数

按语言统计选中的文件夹里有多少个代码文件、多少行，可以复制成 Markdown 表格

对比文件

对比选中的两个文本文件（代码、Markdown、配置、CSV……），标出删去和新增的行，改动的地方逐词标出；按修改时间，旧的当原文

批量重命名

给选中的文件统一改名：编号、替换文字、加前后缀、按照片的拍摄时间、改大小写，先看预览再改，改完可以撤销

压缩和解压

把选中的文件或文件夹压缩成 zip，存在原来的文件夹里；把选中的 zip 解压到旁边的同名文件夹里

在终端打开

在「终端」里打开选中的文件夹（选中文件时打开它所在的文件夹）
