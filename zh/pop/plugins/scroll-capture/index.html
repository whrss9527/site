滚动截图

框选一块区域，一边往下滚动一边截，拼成一张长图；网页、聊天记录、长文档都能截全，还能接着识别文字。正在截的时候再用一次就是完成。

怎么用

选中内容，按住右键，一划。动画按步骤播放，点一下某一步可以从那里重看。

  1. 打开要截的网页或者聊天什么都不用选。
  2. 按住鼠标右键大约 0.25 秒。轻点一下还是平常的右键菜单。
  3. 划向「滚动截图」，松开它在圆盘上你放的那一格，「全部功能」里也随时找得到。
  4. 框选会滚动的那一块只框住会滚动的那一块最好。
  5. 一边往下滚动一边截
  6. 再用一次就是完成可以接着识别文字。

能做什么

框选一块区域，一边往下滚动一边截，拼成一张长图。

固定不动的工具栏和底栏只留一份。

正在截的时候再用一次就是完成。

安装

插件不跟着 Pop 一起下载，要用时再装。

1在设置里装

在 Pop 的「设置 → 功能」最上面的「插件」里找到「滚动截图」，点「安装」：从 Pop 的 GitHub 发布页下载，几秒就好，装好就能用，不用重启。

2或者在圆盘上装

在圆盘的「全部功能」里搜「滚动截图」：没装的插件列在后面，点一下就装上，能处理当前选中的内容时直接运行。

3然后，怎么顺手怎么用

在「设置 → 圆盘」里把它放上圆盘、给它设个快捷键，或者在快捷指令和脚本里用它的链接：

pop://run?plugin=scrollCapture

不用了在同一个列表里点「卸载」，插件和它的设置一起删掉。Pop 更新后，装着的插件会跟着换成新版本；打开 iCloud 同步的话，装了哪些会同步到你的其他 Mac。

更多录屏和演示

录屏

拖出一块区域、单击选一个窗口或者按回车录整个屏幕，存成 MP4；可以录上电脑里的声音或者麦克风、显示鼠标点击和按下的键，录好能接着转成 GIF。正在录的时候再用一次就停止

录音

用麦克风录一段声音，存成 .m4a 放进「下载」；录的时候屏幕上方有个小条，看得到时长和音量，可以暂停，录好能接着转成文字。正在录的时候再用一次就停止

显示按键

演示、录教程时在屏幕下方显示按下的组合键（⌘C、⇧⌘4、方向键这些），普通打字不显示；再用一次关闭。录屏时也可以勾选一起录进去

屏幕画笔

演示、录教程时直接在屏幕上画：画笔、荧光笔、箭头、方框、椭圆，笔迹可以几秒后自动消失，也可以留着去操作下面的窗口，录屏时一起录进去；Esc 或再用一次结束

摄像头小窗

在屏幕角落用一个圆形小窗显示摄像头画面，录教程、演示时把自己也放进画面；拖动换位置，滚动或双击换大小，右键换形状和摄像头。再用一次关闭

突出显示指针

演示、录教程时在指针周围加一圈黄色光圈，按下鼠标时泛起波纹，让人一眼看到指针在哪；再用一次关闭
