whrss9527 做的 Mac 应用

安静的小工具，
住在你的菜单栏里。

四个原生 Swift 写的 macOS 工具：右键工具箱、菜单栏管理、股票行情和代理开关。同一种玻璃质感，不打扰你，也不收钱。

看看这些应用 GitHub 主页

应用

每个应用只在菜单栏里做好一件事。下载按钮会打开 GitHub 上的最新版本。

Pop

长按右键，一划即达：翻译、换算和 80 多个小工具。

  • 选中外文直接翻译：系统离线翻译、AI 或 DeepL
  • 圆盘里的功能随你摆：换算、识字、取色、JSON、文件
  • 剪贴板历史、贴图、插件，AI 用你自己的接口

macOS 15 或更新 · Apple 芯片与 Intel 通用 · GPL-3.0

下载 了解更多

Meno

安静的菜单栏，由玻璃打造：隐藏、收起、随时唤回图标。

  • 显示、隐藏，再加一个放几乎用不到图标的暗格
  • 暂存条和快速打开，macOS 26 上是 Liquid Glass
  • 规则、场景，一键禅模式，演示录屏更干净

macOS 14 或更新 · Apple 芯片与 Intel 通用 · GPL-3.0

下载 了解更多

Stox

A 股、港股、美股，一眼看盘，一键隐身。

  • A 股、港股、美股，还有指数、基金和外汇
  • 持仓与盈亏、价格提醒、iCloud 同步
  • 右键点一下菜单栏图标，数字全部藏起来

macOS 13 或更新 · Apple 芯片与 Intel 通用 · GPL-3.0

下载 了解更多

Proxi

一个开关管好系统代理、终端、git 和 npm，内置 mihomo 内核。

  • 系统代理、环境变量、git、npm 一个开关
  • 内置 mihomo 内核：订阅、分流规则、策略组
  • 局域网共享给游戏机和手机，增强模式与网关模式

macOS 14 或更新 · Apple 芯片与 Intel 通用 · GPL-3.0

界面语言：Meno 支持英文、简体中文和繁体中文；Pop、Stox、Proxi 目前是简体中文界面。

它们的共同点

原生 Swift，Apple 芯片和 Intel 通用，玻璃质感的界面在 macOS 26 上变成 Liquid Glass。

签名并经过公证

现在发布的版本都用 Developer ID 签名并通过苹果公证。下载、解压、双击就能打开。

一键更新

直接从 GitHub Releases 检查新版本，比对 SHA-256 校验和与代码签名，替换后自动重新打开。

数据留在你这儿

不用注册，没有统计，也没有我的服务器。数据只在你的 Mac 或你自己的 iCloud 里。

开源

四个应用都以 GPL-3.0 开源。可以读代码、自己编译，也欢迎提交修改。
