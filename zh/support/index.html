支持

求助最快的办法是在 GitHub 上提 issue：它是公开的，答案也能帮到后来的人。不方便公开的事，可以给我写信。

Pop

更新后右键没反应？打开设置 › 通用，点“清除旧的授权记录”，再重新授予辅助功能权限。

邮件

不想公开的问题、安全问题报告，以及和隐私、个人数据有关的事，请写信到 whrss9527@gmail.com。每封信我都会看，回复可能要等几天。中文、英文都可以。

好的问题报告包括

  1. 应用的版本号（在它的设置或“关于”页面里）和 macOS 版本。
  2. Apple 芯片还是 Intel。
  3. 你做了什么、预期是什么、实际发生了什么。
  4. 和界面有关的问题，附上截图或录屏。

写信之前

  1. 先更新。每个应用都能自己更新，问题可能已经修好了。
  2. 更新后的权限问题。用到辅助功能权限的应用（Pop、Meno）如果没反应，到系统设置 › 隐私与安全性 › 辅助功能里把它移除再重新添加，或者用应用里的重置按钮。
  3. 提示“无法打开”。现在发布的版本都经过公证，双击就能打开。很早的版本没有公证：右键点应用选“打开”，或者下载最新版本。
