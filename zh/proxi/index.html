Proxi

/ˈprɒk.si/ —— 还是 proxy，只是 y 换成了 i。

一个开关管好系统代理、终端环境变量、git 和 npm；还内置 mihomo 内核，支持订阅和分流规则、局域网共享，以及增强模式（TUN）和网关模式。

下载 Proxi 在 GitHub 上查看

开源免费macOS 14 或更新Apple 芯片与 Intel简体中文界面

一个开关，处处生效

建一个代理配置（HTTP、SOCKS5 或 PAC），选好它作用在哪里：系统代理、新开的终端和应用的环境变量、git 和 npm。一键切换配置，或者按 ⌃⌥P。

  • 发现其他应用改了代理时会提示你，还能把它存成一个配置
  • 自动发现你 Mac 上已经在运行的代理软件并添加进来
  • 菜单栏里直接显示上传和下载速度

订阅和规则，内置就有

粘贴订阅地址，节点就出现在面板里。手动选一个，或者让 Proxi 自动选最快的，再按规则分流。引擎是 mihomo（Clash Meta），打包在应用里。

  • 策略组：手动选择、自动选择、故障转移和负载均衡
  • 规则库收录 blackmatrix7、MetaCubeX、ACL4SSR 和 Shadowrocket 规则集
  • 导入 Clash、mihomo、Surge、Shadowrocket 和 Quantumult X 配置，可以预览和撤销

整台 Mac，连游戏机也算上

增强模式通过虚拟网卡，让每个应用（包括终端和游戏）都经过内核。局域网共享和网关模式让 PS5、Switch 或手机和你的 Mac 用同一个连接。

  • 局域网共享使用 7892 端口，默认只允许局域网地址连接
  • 网关模式适合不能设置代理的设备，游戏的 UDP 流量也能处理
  • 一个小小的特权助手，输一次密码安装，只在这两种模式下使用

脚本、AI 助手和同步

proxi 命令行工具、给 AI 助手用的 MCP 服务器和 proxi:// 网址命令，共用一个本地控制接口，有四档权限。设置可以通过你自己的 iCloud 云盘在多台 Mac 之间同步。

  • 按 Wi-Fi 网络或路由器自动切换配置
  • 导入和自动切换都记在操作记录里；导入可以撤销

连不上的时候

连接

经过内核的每一条连接：来自哪个应用或设备、命中哪条规则、走哪个节点、用了多少流量。

服务检测

看看 ChatGPT、Claude、Gemini、Netflix、YouTube Premium 或 Telegram 通过某个节点能不能用，被识别为哪个地区。

网址诊断

输入打不开的网站，Proxi 会逐一检查 DNS、直连和代理路径，并给出修复建议。

出口 IP

网站通过你的节点看到的地址和地区，以及你 Mac 自己的公网地址。

进阶 DNS

内核自带加密 DNS、按域名指定服务器、hosts，以及保存前会先检查的 mihomo 配置补丁。

健康检查

代理开启时定期检查代理端口，没有响应时提醒你。

安装与更新

  1. 从最新版本下载 Proxi-macos.zip 并解压。
  2. 把 Proxi.app 拖进“应用程序”文件夹，双击打开。从 0.11.1 起，发布的版本都用 Developer ID 签名并通过苹果公证。
  3. 点菜单栏图标，添加一个代理配置或订阅，打开开关。

Proxi 在启动时和之后每 6 小时检查一次 GitHub Releases（可以关闭）。点“更新”会下载适合你芯片的版本，比对 SHA-256，替换 Proxi 并重新打开。签名版本只会安装同一开发者签名的更新。Proxi 以前叫 ProxySwitch；从 ProxySwitch 更新时，设置会自动迁移过来。

常见问题

免费吗？

免费。Proxi 以 GPL-3.0 开源。它不出售也不提供代理服务器，代理或订阅需要你自己准备。

需要辅助功能权限吗？

不需要。全局快捷键用的是标准热键接口。Proxi 真正需要的是：修改系统代理时的管理员密码；以及只有使用增强模式或网关模式时，要安装一次特权助手，因为虚拟网卡和 IP 转发需要 root 权限。

mihomo 是什么？

mihomo（Clash Meta）是一个开源代理内核，同样采用 GPL-3.0。Proxi 把它作为独立程序打包在应用里，只在你使用内置节点代理、局域网共享或增强模式时运行。

局域网共享安全吗？

默认只允许私有局域网网段（10.x、172.16–31.x、192.168.x）的设备连接，你也可以限定为指定的 IP。在公共 Wi-Fi 上请关闭它。

为什么要定位权限？

只用于按 Wi-Fi 网络自动切换：从 macOS 14 起，读取 Wi-Fi 名称需要定位权限。Proxi 不读取也不保存你的位置，你也可以改为按路由器切换。

有 Windows 版吗？

有，Windows 上是 ProxySwitch。两者各自独立发展。
