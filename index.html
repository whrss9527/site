The apps

Each one does a single job from the menu bar. Download buttons go to the latest release on GitHub.

With Homebrew: brew install --cask whrss9527/tap/pop (or meno, stox, proxi).

Pop

Long-press right click: translate, convert and 120+ tools in one swipe.

  • Translate a selection with Apple's on-device translation, AI or DeepL
  • A ring of tools you arrange, and 108 plugins to add when you need them
  • Clipboard history, pinned screenshots, plugins and AI with your own endpoint

macOS 15 or later · Universal (Apple silicon and Intel) · GPL‑3.0

What they have in common

Native Swift, universal binaries for Apple silicon and Intel, and a glass interface that turns into Liquid Glass on macOS 26.

Signed and notarized

Current releases are signed with a Developer ID and notarized by Apple. Download, unzip, double-click.

Updates itself

Each app checks GitHub Releases, verifies the SHA-256 checksum and code signature, replaces itself and relaunches.

Private by default

No accounts, no analytics, no servers of mine. Your data stays on your Mac or in your own iCloud.

Open source

All four are free software under GPL-3.0. Read the code, build it yourself, send a fix.
